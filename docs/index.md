## Selected Evaluation Criteria

| № | Criterion | Scope in the project |
|---|---|---|
| 1 | Back-end | Data processing and selector management. A dedicated service aggregates "hot words" from parsed vacancies and builds skills analytics. The server acts as a registry of dynamic CSS selectors: it receives new site structures from the browser extension, deduplicates vacancies, and distributes updated parsing rules without restarting clients. |
| 2 | Front-end | Local storage and user dashboard. The PWA covers visual management of automatic applications and analytics visualization. The client side manages a local database for personal data and sessions, a filter configuration interface, and application status tracking. |
| 3 | Adaptive UI | Mobile access to management and analytics. Adaptation of the PWA dashboard for smartphones and tablets. |
| 4 | Database | Storage of unstructured vacancies and caching. Accumulation of raw vacancy data from different platforms; caching of frequently requested selectors and keywords. |
| 5 | AI Assistant | Intelligent text processing and matching. Semantic analysis comparing resume text with vacancy requirements to calculate a match score, and automatic generation of personalized cover letters. |
| 6 | Containerization | Building and independently running the back-end service, the background data collector, and databases in an isolated network. |
| 7 | API documentation | Specification of endpoints, data exchange formats, and error structures between the PWA, the browser extension, and the back-end. |
